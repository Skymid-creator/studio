# **App Name**: FocusPrompt

## Core Features:

- Customizable Intervals: Allow users to set a custom interval for focus prompts (e.g., every 2 minutes).
- Focus Notification: Display a non-intrusive browser notification at the set interval, asking 'Are you focusing?' The notification should be seen even if the user is on another application. So it should be integrated as a browser notification.
- Notification Customization: Offer options for different notification sounds or display styles.
- Tracking: Keep track of the frequency and response of the focus prompts.
- Generative AI Powered Focus Tips: Uses an LLM tool to give helpful personalized focus tips. These can include simple stretches, breathing exercises or articles to help with focus. This can happen periodically as a supplement to the notifications.

## Style Guidelines:

- Primary color: Calm light blue (#ADD8E6) to promote a sense of focus and tranquility.
- Background color: Soft off-white (#FAFAFA), providing a gentle contrast and reducing eye strain.
- Accent color: Muted green (#90EE90) for subtle visual cues and positive reinforcement.
- Body and headline font: 'Inter', a sans-serif, for a clean and readable interface.
- Use simple, clear icons to represent settings and customization options.
- Prioritize a clean and distraction-free interface to maintain user focus.
- Use subtle, non-intrusive animations for notifications and user interactions.
